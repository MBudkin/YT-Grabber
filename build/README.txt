YT Grabber для Windows 10/11 x64

1. Полностью распакуйте YT-Grabber.zip и запустите Install.bat.
   Помощник и программы для загрузки и конвертации входят в комплект.
   Установка выполняется для текущего пользователя без прав администратора.
2. В Chrome откройте chrome://extensions и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение». Вставьте скопированный
   установщиком путь и подтвердите выбор папки. Если нужен путь вручную:
   %LOCALAPPDATA%\YT Grabber\extension
4. На странице видео нажмите значок YT Grabber и выберите формат.

Видео по умолчанию сохраняются в папке «Загрузки\YT Grabber».
Обновления устанавливаются из расширения (Настройки → Обновления).
Вручную: распакуйте новый архив и снова запустите Install.bat.
Для удаления запустите Uninstall.bat и удалите расширение в браузере.
Скачанные видео сохранятся.

YT Grabber for Windows 10/11 x64

1. Extract YT-Grabber.zip completely and run Install.bat (no admin rights needed).
2. In Chrome open chrome://extensions and turn on Developer mode.
3. Click "Load unpacked", paste the path copied by the installer and confirm:
   %LOCALAPPDATA%\YT Grabber\extension
4. On a video page click the YT Grabber icon and pick a format.

Updates are installed from the extension (Settings -> Updates).
To uninstall, run Uninstall.bat and remove the extension. Downloads are kept.
